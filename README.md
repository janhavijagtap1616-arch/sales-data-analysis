
# Sales Data Analysis Using Python

## Project Overview
A Python-based project that analyzes sales data, identifies top-performing products, compares regional sales, and visualizes monthly sales trends.

## Features
- Data cleaning and preprocessing
- Product-wise and region-wise sales analysis
- Top 3 products identification
- Monthly sales trend analysis
- Data visualization using charts and heatmaps
- Export of cleaned data and analysis results

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## How to Run
1. Install Python.
2. Install the required libraries using:
   `pip install -r requirements.txt`
3. Keep the dataset in the project folder.
4. Run:
   `python sales_analysis.py`
